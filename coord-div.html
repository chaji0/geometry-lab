선분의 외분점

두 점 A(x1, y1, z1), B(x2, y2, z2)에 대하여 선분 AB를 m : n (m > 0, n > 0, m ≠ n)으로 외분하는 점의 좌표는 (mx2 − nx1m − n, my2 − ny1m − n, mz2 − nz1m − n)
특히 선분 AB의 중점의 좌표는 (x1 + x22, y1 + y22, z1 + z22)
변 BC의 중점 M(x4, y4, z4):  x4 = x2 + x32, y4 = y2 + y32, z4 = z2 + z32
점 G는 선분 AM을 2 : 1로 내분하는 점이므로
x = 2x4 + x12 + 1 = x1 + x2 + x33,  y = 2y4 + y12 + 1 = y1 + y2 + y33,  z = 2z4 + z12 + 1 = z1 + z2 + z33
G(x1 + x2 + x33, y1 + y2 + y33, z1 + z2 + z33)

삼각형의 무게중심

좌표공간의 세 점 A(x1, y1, z1), B(x2, y2, z2), C(x3, y3, z3)을 꼭짓점으로 하는 삼각형 ABC의 무게중심의 좌표는 (x1 + x2 + x33, y1 + y2 + y33, z1 + z2 + z33)
