벡터의 성분

평면벡터의 성분
좌표평면에서 두 점 E1(1, 0), E2(0, 1)의 위치벡터를 각각 e1, e2라 하자.
벡터 a의 종점을 A(a1, a2)라 하면
a=OA=OA1+OA2
=a1e1+a2e2
a=a1e1+a2e2
= (a1, a2) x성분y성분
e1, e2: 기본단위벡터  ·  a1, a2: a의 성분
평면벡터의 크기, 두 평면벡터가 서로 같을 조건
두 평면벡터 a = (a1, a2), b = (b1, b2)에 대하여
1|a| = √a12 + a22
2a = b ⟺ a1 = b1, a2 = b2
성분으로 나타낸 평면벡터의 연산
두 평면벡터 a = (a1, a2), b = (b1, b2)에 대하여
1a + b = (a1 + b1, a2 + b2)
2a − b = (a1 − b1, a2 − b2)
3ka = (ka1, ka2) (단, k는 실수)
평면벡터의 성분과 크기
두 점 A(a1, a2), B(b1, b2)에 대하여
1AB = (b1 − a1, b2 − a2)
2|AB| = √(b1 − a1)2 + (b2 − a2)2
확인a = (2, 3), b = (4, −1)일 때, 3a − 2b = 3(2, 3) − 2(4, −1) = (6, 9) − (8, −2) = (−2, )
예제 3a = (0, −1), b = (3, 2), c = (−3, −5)일 때, c = ka + lb를 만족시키는 실수 k, l의 값을 구하시오.
공간벡터의 성분
좌표공간에서 세 점 E1(1, 0, 0), E2(0, 1, 0), E3(0, 0, 1)의 위치벡터를 각각 e1, e2, e3이라 하자.
그림을 누르면 점 A가 나타납니다
벡터 a의 종점을 A(a1, a2, a3)이라 하면
a=a1e1+a2e2+a3e3
= (a1, a2, a3) x성분y성분z성분
두 공간벡터 a = (a1, a2, a3), b = (b1, b2, b3)에 대하여
1|a| = √a12 + a22 + a32
2a = b ⟺ a1 = b1, a2 = b2, a3 = b3
성분으로 나타낸 공간벡터의 연산, 공간벡터의 성분과 크기
두 점 A(a1, a2, a3), B(b1, b2, b3)의 위치벡터 a = (a1, a2, a3), b = (b1, b2, b3)에 대하여
1a + b = (a1 + b1, a2 + b2, a3 + b3)
2a − b = (a1 − b1, a2 − b2, a3 − b3)
3ka = (ka1, ka2, ka3) (단, k는 실수)
4AB = (b1 − a1, b2 − a2, b3 − a3)
5|AB| = √(b1 − a1)2 + (b2 − a2)2 + (b3 − a3)2
내 역량오른쪽 그림에서 정육면체의 내부의 임의의 점 P에 대하여
PA + PG = PD + PF
가 성립한다. 다음 서하의 말을 이용하여 등식이 성립함을 보이고 친구에게 설명하시오.
서하
벡터는 성분으로 나타낼 수 있으므로 정육면체를 좌표공간 위에 놓고 생각해 봐.

다른 증명 방법

방법 1중점 M으로 쪼개기
PA = PM + MA
+)PG = PM + MG
PA + PG = 2PM
PD = PM + MD
+)PF = PM + MF
PD + PF = 2PM
방법 2이항해서 뺄셈으로
PA + PG = PD + PF
PA − PD = PF − PG
DA = GF (평행하고 길이가 같은 모서리)
방법 3기준점 O의 위치벡터로
PA + PG = OA + OG − 2OP
= 2 · OA + OG2 − 2OP
= 2OM − 2OP
= 2PM
PD + PF = OD + OF − 2OP
= 2 · OD + OF2 − 2OP
= 2OM − 2OP
= 2PM
방법 4점대칭으로 일반화
M을 지나는 선분 XY(M이 중점)에 대하여 항상 PX + PY = 2PM이다. 정육면체의 네 대각선 AG, DF, BH, CE는 모두 M에서 서로를 이등분하므로
PA + PG = PD + PF = PB + PH = PC + PE = 2PM
정육면체일 필요도 없다. 네 점 A, G, D, F가 서로를 이등분하는 두 선분의 끝점(평행사변형의 꼭짓점)이기만 하면 성립한다.
탐구메테인 분자의 구조
메테인(CH4) 분자는 정사면체의 네 꼭짓점에 각각 하나의 수소(H) 원자가 있고, 탄소(C) 원자는 네 꼭짓점에서 마주 보는 면에 내린 수선의 교점에 있는 대칭 구조이다. 정사면체 H1H2H3H4의 꼭짓점이
H1(6, 0, 0), H2(0, 6, 0), H3(0, 0, 6), H4(6, 6, 6)
일 때, 삼각형 H1H2H3, H1H2H4의 무게중심을 각각 G1, G2, 선분 H1H2의 중점을 M이라 하자. 점 C는 선분 H4G1과 H3G2의 교점이다.
메테인 분자분자를 누르면 좌표공간 위에 놓입니다

[그림 2] 삼각형 H3MH4
문제CH1 + CH2 + CH3 + CH4 = 0임을 확인하시오.
STEP 1G1(2, 2, 2), G2(4, 4, 2)이므로 G1G2 = (2, 2, 0) = 13H3H4  ⇒  G1G2 ∥ H3H4
STEP 2△CG1G2 ∽ △CH4H3(닮음비 1 : 3)이므로 G1C : CH4 = G2C : CH3 = 1 : 3  ⇒  C(3, 3, 3)
STEP 3CH1 + CH2 + CH3 + CH4 = (3, −3, −3) + (−3, 3, −3) + (−3, −3, 3) + (3, 3, 3) = (0, 0, 0) = 0
