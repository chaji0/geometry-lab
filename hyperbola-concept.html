📕 쌍곡선 개념 정리

식을 눌러 그래프를 켜고 끄면서, a·b 값을 움직여 초점·꼭짓점·주축·점근선을 살펴보세요

1. 쌍곡선의 뜻

평면 위의 두 점 F, F′으로부터의 거리의 차가 일정한 점들의 자취를 쌍곡선이라 합니다.
· 두 점 F, F′ → 초점
· 쌍곡선이 직선 FF′과 만나는 두 점 A, A′ → 꼭짓점
· 선분 AA′ → 주축
· 주축의 중점(= 두 초점의 중점) → 중심
· 곡선이 한없이 가까워지는 두 직선 → 점근선 (오른쪽 그래프의 하늘색 점선)

2. 쌍곡선의 방정식

(1) 초점이 x축 위에 있을 때 — 좌우로 벌어진 쌍곡선
x2a2 − y2b2 = 1
초점 F(c, 0), F′(−c, 0) — c = √(a² + b²)
꼭짓점 A(a, 0), A′(−a, 0) · 거리의 차 = 주축의 길이 = 2a
👆 카드를 누르면 그래프를 켜고 끌 수 있어요
(2) 초점이 y축 위에 있을 때 — 위아래로 벌어진 쌍곡선
x2a2 − y2b2 = −1
초점 F(0, c), F′(0, −c) — c = √(a² + b²) (같아요!)
꼭짓점 B(0, b), B′(0, −b) · 거리의 차 = 주축의 길이 = 2b
👆 카드를 누르면 그래프를 켜고 끌 수 있어요
🔎 두 쌍곡선을 함께 켜 보세요 — 점근선 y = ±(b/a)x가 완전히 똑같아요! 이렇게 우변만 1과 −1로 다른 두 쌍곡선을 켤레쌍곡선이라고 해요.
a = 2
b = 1.5
📐 하늘색 점선 = 점근선 y = ±(b/a)x — 두 경우가 같은 점근선을 공유해요 (타원과 달리 c² = a² + b²!)
