벡터의 내적의 성질
세 벡터 a, b, c에 대하여 1a·b = b·a (교환법칙) 2a·(b + c) = a·b + a·c,  (a + b)·c = a·c + b·c (분배법칙) 3(ka)·b = a·(kb) = k(a·b) (단, k는 실수)
성질이 성립하는 이유 (성분으로 확인하기) ▾
세 벡터 a = (a1, a2), b = (b1, b2), c = (c1, c2)에 대하여 다음이 성립한다. 1a·b = a1b1 + a2b2 = b1a1 + b2a2 = b·a누르면 전개 2a·(b + c) = (a1, a2)·(b1 + c1, b2 + c2) = a1(b1 + c1) + a2(b2 + c2)누르면 전개 = (a1b1 + a2b2) + (a1c1 + a2c2) = a·b + a·c (a + b)·c = (a1 + b1, a2 + b2)·(c1, c2) = (a1 + b1)c1 + (a2 + b2)c2누르면 전개 = (a1c1 + a2c2) + (b1c1 + b2c2) = a·c + b·c 3실수 k에 대하여누르면 전개 (ka)·b = (ka1, ka2)·(b1, b2) = ka1b1 + ka2b2 = a1(kb1) + a2(kb2) = (a1, a2)·(kb1, kb2) = a·(kb) 같은 방법으로 (ka)·b = k(a·b)도 성립한다.
평면벡터와 마찬가지로 공간벡터에서도 위의 내적의 성질이 성립한다.
