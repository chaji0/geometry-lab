연어는 산란기가 되면 자신이 태어난 강으로 돌아가 알을 낳는다. 연어와 강물의 속도를 각각 a, b라고 하면 연어와 강물의 속력은 각각 |a|, |b|이다. 이때 강물의 흐름과 같은 방향으로 이동하는 연어의 실제 속력은 |a + b| = |a| + |b|이고, 강물의 흐름과 반대 방향으로 이동하는 연어의 실제 속력은 |a + b| = |a| − |b|이다. 오른쪽 그림과 같이 연어가 방향을 바꾸어 이동할 때, 다음이 성립함을 설명하시오.
|a| − |b| < |a + b| < |a| + |b|
